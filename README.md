# Quiz Game — Arden's Arcade

A simple, interactive trivia quiz game built with HTML, CSS, and vanilla JavaScript.

Choose a category, select a difficulty level, decide how many questions to answer, and test your knowledge.

## Live Demo

[Play Quiz Game](https://quizgame-byarden.netlify.app)

## Features

- Choose a trivia category or play with any category.
- Select Easy, Medium, or Hard difficulty, or use mixed difficulty.
- Choose between 5, 10, 15, and 20 questions.
- Fetch multiple-choice trivia questions from the Open Trivia Database.
- Track your score as you answer questions.
- View your results at the end of a quiz.
- Responsive interface for different screen sizes.
- No frontend framework or build tools required.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [Open Trivia Database](https://opentdb.com/) — trivia questions API

## Getting Started

### Run locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

4. Select your quiz preferences and start playing.

An internet connection is required to fetch questions from the API.
